## 📊 ระบบซิงก์ข้อมูลลง Excel / Google Sheets อัตโนมัติ (NEW!)

เว็บไซต์นี้มีระบบรับข้อมูลข้อเสนอแนะและเรื่องร้องเรียนจากนักเรียน แล้วส่งตรงไปยัง **Google Sheets / Microsoft Excel** แบบเรียลไทม์:

### 3 ขั้นตอนง่ายๆ ในการเชื่อมต่อ:
1. **สร้าง Google Sheet**: ตั้งหัวตาราง 9 ช่อง (`วันเวลา`, `รหัสตั๋ว`, `หมวดหมู่`, `ความเร่งด่วน`, `หัวข้อเรื่อง`, `รายละเอียด`, `ชื่อผู้ส่ง`, `รหัสนักเรียน`, `สถานะ`)
2. **ผูก Google Apps Script**: ไปที่ `ส่วนขยาย` > `Apps Script` วางโค้ด `doPost(e)` แล้วกด `Deploy` > `Web app` (เลือกผู้มีสิทธิ์เข้าถึงเป็น "ทุกคน/Anyone")
3. **นำ URL มาใส่ใน `app.js`**: วางลิงก์ที่บรรทัดที่ 10:
   ```javascript
   const GOOGLE_SHEET_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
   ```

### 📥 ฟังก์ชันดาวน์โหลด Excel (.CSV) ในตัว:
* แม้จะไม่ได้เชื่อมต่อเน็ตหรือยังไม่ได้ผูก Google Sheet ข้อมูลทุกเรื่องที่นักเรียนส่งจะถูกบันทึกสำรองไว้ในเครื่อง
* คณะกรรมการสภาสามารถกดปุ่ม **"ดาวน์โหลดตารางข้อมูลเป็น Excel (.CSV)"** ที่หน้าเว็บไซต์ได้ตลอดเวลาเพื่อเปิดใน Microsoft Excel ทันที!
